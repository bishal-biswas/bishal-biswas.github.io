## Who this is for

Businesses and founders who need more than a brochure site: dashboards, customer portals, internal tools, SaaS products and anything with user accounts, forms and data behind it.

## Typical stack

| Layer | Options |
| --- | --- |
| Frontend | Astro, React, Angular, Tailwind CSS |
| Backend | ASP.NET Core Web API, Node.js |
| Database | SQL Server, MongoDB, Supabase (Postgres), Xata |
| Auth | ASP.NET Identity, JWT, Supabase Auth |
| Hosting | Azure, Vercel, Netlify, VPS |

## How I work

1. **Scope** - we break the product down into milestones so you see working software early.
2. **Build** - each milestone ships to a staging URL with automated tests where they add value.
3. **Harden** - authentication, validation, rate limiting and backups are handled before launch, not after.
4. **Deploy & support** - CI/CD to your host of choice, plus documentation and an optional maintenance retainer.
