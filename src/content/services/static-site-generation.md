## Who this is for

Anyone who needs a website that is fast, cheap to host and easy to keep online: personal portfolios, company landing pages, documentation sites and blogs. If your content changes a few times a week rather than a few times a second, a static site is almost always the right call.

## How I work

1. **Discovery** - we agree on the pages, the content you already have and the design direction.
2. **Build** - I set the site up in Astro (or Jekyll / Next.js if you prefer), wire up a headless CMS such as Decap so you can edit content yourself, and add analytics, SEO metadata and an RSS feed where it makes sense.
3. **Launch** - the site is deployed on GitHub Pages, Netlify, Vercel or your own host, with a CI pipeline that rebuilds it on every content change.
4. **Handover** - you get the repository, a short guide to editing content and a walkthrough call.

## What you get

- A production-ready repository you own outright.
- Lighthouse scores in the green for performance, accessibility and SEO.
- A content workflow that does not require a developer for day-to-day edits.
